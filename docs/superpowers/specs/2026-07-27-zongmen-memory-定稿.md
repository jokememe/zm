# 宗门记忆定稿（不写代码 · 产品边界）

> 日期：2026-07-27  
> 状态：**已按 P0–P3 落地（beta）**；细节以代码为准，冲突仍以本定稿分层为准。  
> 取代口径：旧「表格当记忆 / 纪要 LLM 主召回 / 只吹图谱不生长」均作废。  
> 参考：柏宝书（自动摘要+台账+可选向量）、Nocturne（URI/触发/boot/可审）、现有方案 C 图谱。

---

## 1. 一句话

**经营归经营；人物靠图谱；长线靠摘要层级；向量与 VPS 只做可选增强。**  
主路径必须在浏览器内跑完，**不依赖 MCP、不依赖 tools**。

---

## 2. 为什么这样定（贴合本游戏）

| 玩家真实痛点 | 谁负责 | 不负责的方案 |
|--------------|--------|--------------|
| 谁和谁有仇/有约、刚做了什么 | **角色记忆图谱** | 整表 dump、纯向量 |
| 几十上百回主线还接得上、token 不炸 | **短/中/长摘要层级**（学柏宝书） | 只靠 16 条热 beats |
| 灵石/弟子/城池算对 | **经营存档 + 结算**（另册） | 叙事记忆系统 |
| 人在哪、关键物别复制扣 | **轻量叙事状态**（可选加强，学柏宝书在场门控） | 当「记忆主 UI」 |
| 语义捞很久以前的细节 | **可选向量** | 默认唯一召回 |
| 你自己跨工具同一份记忆 | **可选 VPS/Nocturne HTTP** | 全体玩家默认路径 |

**精神导师权重：**

- 产品形态偏 **柏宝书**（自动记、省 token、状态贴最近、向量可选）  
- 人物表达偏 **图谱**（侧栏「角色记忆」是脸面）  
- 基础设施 **有 VPS 再挂 Nocturne**，不当底座  

---

## 3. 四层模型（唯一合法分层）

```
┌─────────────────────────────────────────────────────────┐
│ L0 经营层（非记忆 UI）                                    │
│     资源/名册/城池/结算 · 可与叙事同步 · 禁止整表灌世界书   │
├─────────────────────────────────────────────────────────┤
│ L1 人物图谱（默认开 · 产品主路径）                         │
│     节点/边/近事 beats · 冷档案闪回 · 侧栏「角色记忆」       │
├─────────────────────────────────────────────────────────┤
│ L2 长线摘要（默认开）                                      │
│     短/中/长 · 回合 <sum> · 预算内注入 · 学柏宝书「目录感」  │
├─────────────────────────────────────────────────────────┤
│ L3 增强（默认关或失败静默）                                 │
│     向量召回 · 模型 tools · VPS/Nocturne HTTP              │
└─────────────────────────────────────────────────────────┘
```

**铁律：**

1. L0 **不是**「记忆」入口；设置文案不得写「注入表格世界状态当记忆」。  
2. L1 + L2 构成 **所有玩家、所有模型** 的完整记忆体验。  
3. L3 任一失败 → 自动回退 L1+L2，**禁止卡死推演**。  
4. **未获你点头，不得擅自删除或恢复** L0 填表代码 / 向量 / 召回侧通道整包——改动前先改本定稿。

---

## 4. 玩家看见什么

| 入口 | 看见 | 不看见 |
|------|------|--------|
| 侧栏 **角色记忆** | 人物列表、关系、近事、旧事条数、空态说明 | 经营表格编辑器当主界面 |
| 弟子详情 | 该人图谱切片 +「打开角色记忆」 | 无关整库 dump |
| 天机状态条 | 「角色记忆 N 人 · 旧事 K」之类选取痕迹 | 假召回 API 成功动画 |
| 密匣 | L1/L2 说明；L3 明确标「可选/要 embeddings 或自建服」 | 来回拆装无说明的开关 |

**空图必须可解释：**  
「尚无近事：通灵需带 `<memory>`，或开启正文兜底生长」——禁止假装已有记忆。

## 5. 读写闭环（无 tools 兼容 · 默认）

### 5.1 读（推演前 · 系统预取）

顺序固定，全部本地（或 L3 外置时先打 API 再合并）：

1. **Boot 锚**（学 Nocturne `system://boot` 思想）  
   固定短块：掌门是谁、宗门底色、当前年季、进行中主线一句。  
2. **L2 摘要**  
   短必带；中/长按预算裁。  
3. **L1 图谱选取**  
   用户话 + 上下文标签 → 点名 → 触发词/弱关键词 → 一跳邻接 → 冷档案有线索才闪回。  
4. **（可选）L3 向量 / VPS**  
   命中追加「语义补充」或远端节点；失败清空该槽。

注入形态：系统世界书 constant 条目（或等价 extension 槽），**历史摘要靠前、人物/状态贴最近**（学柏宝书双槽思想，实现可分期）。

### 5.2 写

| 通道 | 默认 | 说明 |
|------|------|------|
| `<memory>名\|事\|关系` | **主写入** | 解析进 L1；格式容错；坏行丢弃不挡主文 |
| `<sum>` | **主写入** | 进 L2 短层，择要升中/长 |
| 正文人名兜底 | **建议默认开（可关）** | 无标签时弱 beat，防空图；强度低于显式标签 |
| 侧栏手改 | 应支持（可分期） | 改近事/关系；学「人可审」 |
| 经营同步 | 只动 L0 | 可 **投影提示** 到 L1（如弟子入名册建空节点），不反向用表灌记忆全文 |
| 副 API 自动摘要 | 分期 | 学柏宝书；用次渠道整理，不抢主推演 |

### 5.3 有 tools 时（L3）

- 探测成功才挂 `search_memory` / `read_memory` 类工具，读写 **同一套 L1 存储**。  
- 一次失败标记 endpoint 无 tools → 本局回退 5.1。  
- **禁止**「无 tools 就不能玩记忆」。

## 6. 数据与生命周期

| 项 | 约定 |
|----|------|
| L1 存储 | 继续 `zongmen-memory-graph-v1` + 冷档案 IDB（可演进字段：触发词、path、disclosure） |
| L2 存储 | 现有 memory-lore / sum 银行；可演进多层森林，**不必**首期上满柏宝书 UI |
| L0 | 经营存档键；与 L1 **键分离** |
| 开局/清空 | L1+L2+冷档案+L3 向量库一并清；L0 跟「从头开局」策略走 |
| 改名/除名 | 图谱节点合并/删除；边不断悬空 |
| 备份 | 全量备份必须含 L1+L2；L3 向量可重建 |

**与旧设计差异（显式作废）：**

- 不再以「表格投影 = 图谱唯一生长」为主（旧 spec 写入第 1–2 步过时）。  
- 图谱以 **`<memory>` + 兜底 + 手改** 生长；名册可种子空节点。  
- `formatTableMemoryInjection` 不得再当记忆主注入。

## 7. 设置默认值（定稿）

| 项 | 默认 | 备注 |
|----|------|------|
| 角色图谱注入 | **开** | 无开关或仅高级关 |
| 短中长 sum | **开** | 随主文 |
| 正文兜底生长 | **开** | 可关 |
| 向量召回 | **关** | 开后失败静默 |
| 模型 tools 读记忆 | **关/auto** | auto=探测 |
| VPS/Nocturne | **关** | 填 Base URL + Token 才启用 |
| 经营填表/追溯 | 若保留代码：**开但不叫记忆** | 文案与注入隔离 |

未经确认：**不**把默认改成 embedding/both，**不**默认连公网记忆服。

## 8. 成功标准（怎样算「弄好了」）

1. **空档可生长**：连推 3 回（模型偶发不写标签），侧栏仍能出现人名近事（靠兜底或手改说明）。  
2. **点名必带**：用户消息含弟子名 → 注入块出现该人近事/关系（有则带，无则仍有节点壳）。  
3. **长局不炸**：隐藏/压缩旧楼 + L2 目录感，主上下文不以全文堆历史。  
4. **经营不错位**：改记忆不直接改灵石；改灵石不伪装成角色记忆。  
5. **弱模型可用**：关闭一切 L3，仅 L1+L2，推演与记忆仍完整。  
6. **可解释**：状态条/空态不说假话。

## 9. 分期（确认后的实现顺序 · 仍须你下令开干）

| 期 | 内容 | 不做 |
|----|------|------|
| **P0 止血** | 空图生长（兜底+提示）；注入仅 L1+L2；文案与入口统一「角色记忆」；禁止表 dump 进世界书 | 不删你未点头的模块文件 |
| **P1 像人** | Boot 锚；触发词；侧栏可编辑近事；选取质量（点名/一跳/预算） | 力导向画布 |
| **P2 长局** | 摘要层级加强（升层规则、双槽位置）；可选副 API 整理 | 全抄柏宝书森林 UI |
| **P3 增强** | 向量可选 + 设置入口；tools auto；VPS HTTP 适配器 | MCP 塞进浏览器；默认公网 |

每期结束对照 §8；不达标不宣称「记忆做好了」。
